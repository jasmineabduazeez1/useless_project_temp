### Project Description
A video game where we have to beat the game by inconvenient methods

### The Problem (that doesn't exist)
For the people that spent too much time infront of a screen

### The Solution (that nobody asked for)
we solved it by creating a fun physical game that forces them to stand up and do something useful instead
